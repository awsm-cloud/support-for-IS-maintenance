git clone - копирования репозитория на локальный компьютер
git status - просмотр состояния файлов
git add - перенос изменений в область подготовленных изменений подготавливая к коммиту
git commit - создает коммит
git push - отправляется локальные изменения в удаленный репозиторий
git branch - управление ветками в репозитории
git pull - получение изменений с удаленного сервера
git checkout - переключение между ветками
git merge - обьединение истории изменений из ветки в текущую активную
git log - просмотр истории коммитов
